# Product Executor

Use when starting a new project or major feature.

## Procedure
1. Read `PROJECT_STATUS.md`.
2. Read product brief, PRD, scope and user flows.
3. Read architecture and build handoff.
4. Produce:
   - problem
   - user
   - value
   - in scope
   - out of scope
   - assumptions
   - risks
   - acceptance criteria
5. Create or update the active phase plan.
6. Stop for clarification if a blocking requirement is missing.

Do not implement the entire product in one uncontrolled step.
