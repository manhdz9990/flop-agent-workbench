# Bug Fixer

1. Reproduce.
2. Capture evidence.
3. Identify likely root cause.
4. Check regression risk.
5. Make the smallest correct fix.
6. Verify the original failure is resolved.
7. Run relevant regression checks.
8. Record root cause if useful.

Do not patch symptoms without understanding the likely failure path.
