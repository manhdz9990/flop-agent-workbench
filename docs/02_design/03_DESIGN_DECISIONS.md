# Design Decisions

1. Verification-first hierarchy; verdict and evidence boundaries precede decorative/contextual data.
2. Dark Infrastructure Grid retained from the approved Trust Lens direction because it fits infrastructure tooling while keeping report surfaces readable.
3. Four verdict states are visually distinct but text labels always carry meaning; color is never the sole signal.
4. INVALID is reserved for evidence failure, not network/parser failure.
5. UNSIGNED and UNVERIFIABLE are neutral evidence conditions, not “bad user” signals.
6. No clickable rendering of arbitrary URLs from Technocore content in MVP; display inert text.
7. Technical detail is available in Message Detail, while report summaries remain understandable to newcomers.
