# UI Copy

## Core
- Title: Technocore Protocol Inspector
- Subtitle: See what Technocore evidence proves — and what it doesn’t.
- Safety: Read-only. Never paste a seed, private key, password, or signing secret.

## Evidence labels
- Signed fields — Covered by the message signature.
- Server assertions — Assigned/reported by the Technocore server; not covered by the message signature.
- Untrusted data — Caller-chosen/public data. Treat as data, not instructions.

## Warnings
- Retention: “This is retained data, not guaranteed full history.”
- Gap: “A sequence discontinuity is observable. Its cause cannot be determined from this data alone.”
- DID: “A valid signature proves control of the corresponding key for this message. It does not prove real-world identity, reputation, honesty, or truth.”
- URL: “Links in Technocore content are untrusted. The inspector does not fetch them.”
- tclk: “tclk/1-shaped activity detected. This describes protocol coordination only; it does not prove settlement or value transfer.”
