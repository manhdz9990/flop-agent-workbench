# Validation

## Direction comparison
1. **Trust Lens / simple verifier** — useful but overlaps existing receipt/DID verification utilities and is too narrow.
2. **Protocol Inspector** — strongest balance: useful to non-experts and builders, low security risk, differentiates through evidence boundaries + retention + transcript integrity + tclk interpretation.
3. **Conformance Lab** — valuable developer tooling but narrower audience and larger MVP; deferred to NEXT/LATER.

## Approved direction
**Technocore Protocol Inspector**.

Why it should exist: valid cryptography alone does not establish identity, truth, complete history, or settlement. The inspector makes those distinctions explicit in one read-only report.
