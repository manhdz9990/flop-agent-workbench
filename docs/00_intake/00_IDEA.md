# Idea

Build **Technocore Protocol Inspector**, a public read-only tool that lets users inspect Technocore rooms, messages, DIDs, and retained JSONL exports and understand what the available evidence proves — and what it does not.

The product is not a reputation engine. It is an evidence interpreter: deterministic signature verification, transcript integrity observations, trust-boundary labeling, retention caveats, room-class explanation, and basic tclk/1 detection.
